打开方式（本轮没有重新打包安装包）

  • 不要用对话里自动弹出的静态预览页，也不要双击本地 HTML 文件：那种地址只托管了 diagnostics.html 一个文件，/health 和应用首页都是 404，检测必然全红。
  • 电脑上重新双击 start-lan.bat（项目根目录），等黑窗口显示 CORS 合计：5/5 通过。本轮改了服务端响应头，必须重启旧黑窗口，否则逐页检测会被 X-Frame-Options: DENY 挡住（页面顶部会自动给出这条提示）。
  • 电脑浏览器打开 http://127.0.0.1:3001/diagnostics.html。
  • 手机连同一 Wi-Fi，浏览器打开 http://电脑IP:3001/diagnostics.html；黑窗口里会打印电脑 IP。
  • 若用开发服务器，也可打开 http://127.0.0.1:5173/diagnostics.html。
  • 桌面/手机 已安装的 App 内暂时还没有这一页：需要等你确认测试结果后重新打包，届时会内置进安装包。

本轮已修复、应该看到的结果

  • 日历页必须有 ≥ 35 个日期格，即使服务不可达也不能只剩星期表头。
  • 顶部不再出现 Cannot read properties of null (reading 'data') 红条。
  • 手机端离线时，设置 / 习惯 / 信息源等非核心模块不再铺满红色网络错误条。
  • 三档宽度下 溢出 = 0；data-layout 分别为 phone / tablet / desktop。
