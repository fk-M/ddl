## 三、本轮补全计划

按「自用能真正跑起来」排序，先补不需要云账号的部分。

### 第一批：数据模型 + 任务能力（核心）
1. 清单分组（文件夹）、清单类型（任务/笔记）、清单归档、复制、垃圾桶
2. 标签体系：独立标签表 + 颜色 + 父子标签
3. 多提醒表 + 稍后提醒 + 持续提醒
4. 附件（本地文件存储）
5. 任务模板 / 笔记模板
6. 撤销（删除/完成，客户端栈）
7. 批量操作
8. 排序（多字段 + 手动拖拽）
9. 智能清单 / 过滤器
10. 默认值设置 + 逾期位置 + 已完成样式 + 12/24 小时制 + 时区

### 第二批：重复规则深水区
11. 农历重复（每年/每月）
12. 工作日重复（每月第一个/最后一个工作日）
13. 遗忘曲线重复
14. 自定义间隔重复
15. 到期重复 vs 完成重复
16. 改重复任务的范围选择（仅本次/以后/全部）

### 第三批：番茄专注
17. 计时器（专注/短休/长休，自动流转）
18. 关联任务 + 常用专注
19. 统计（今日/本周/总计/图表）
20. 音效 + 白噪音

### 第四批：习惯打卡
21. 习惯 CRUD（周期/目标/图标/颜色）
22. 打卡日历 + 连续天数 + 打卡率
23. 跳过/重置/归档

### 第五批：倒数纪念日
24. 倒数日 / 纪念日 / 生日（含农历、每年重复）

### 第六批：视图
25. 看板视图（列 + 拖拽）
26. 周视图 / 年视图 / 时间轴视图
27. Mini 日历
28. 笔记清单视图

### 第七批：外观与数据
29. 主题色 / 深色 / 跟随系统 / 图标皮肤
30. 提醒铃声选择 + 完成音效
31. 导出（JSON/CSV/ICS）+ 导入（JSON/CSV/ICS）
32. 密码锁
33. 全局快捷键 + 命令面板
34. 拼音首字母搜索

### 不做（需云服务/账号，架构留口）
- 团队协作与共享清单（需多用户与权限后端）
- 第三方日历 OAuth 双向同步（需各平台开发者账号）；**改为支持 .ics 订阅**（只读，够自用）
- 微信/邮件提醒推送（需服务端公网 + 邮件服务）
- AI 功能（需 LLM Key，接口已预留）
- 会员支付
